## Leader ZEN Preset loader

- Loads user presets on a Leader ZEN waveform monitor range (LV5600, LV7600 etc)
- Telnet protocol needs to be enabled on your device and connected to the network with static IP address
- 60 user preset buttons are automatically generated when module has connected
- Connect to device using IP address.
- Select model from the drop down list for authentication
- Companion will display 60 user preset buttons for the 60 user presets available on the unit (not all will be populated depending on user configuration)
- From the button panel open up module presets and select the connected device you have setup, to view the pre-made buttons.
- Drag user preset button to the button panel.
- Open button panel and press the button - User Preset gets loaded on the device if successful

NOTE: Feedback is provided on successful load when the command has been sent. It can not determine if the actual preset has loaded on the unit itself.
