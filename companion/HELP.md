## Leader ZEN Preset loader

- Loads user presets on a Leader ZEN waveform monitor range (LV5600, LV7600 etc)
- Telnet protocol needs to be enabled on your device and connected to the network with static IP address
- 60 user preset buttons (1-60) are automatically genereated when module has connected 
- Button feedback when preset has been selected.
NOTE: This only indicates that the button has been pressed and the command sent to the unit. It does not actually confirm if the preset has been loaded - there is no API feedback)
