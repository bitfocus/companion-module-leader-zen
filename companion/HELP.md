## Leader ZEN Preset loader

- Loads user presets on a Leader ZEN waveform monitor range (LV5600, LV7600 etc)
- Telnet protocol needs to be enabled on your ZEN device and connected to the network with static IP address
- 60 user preset buttons (1-60) are automatically genereated when module has connected 
- Button feedback when preset has been selected.
NOTE: Button feedback only indicates that the button has been pressed and the command sent to the unit. It does not actually confirm if the preset has been loaded - there is no API feedback)

Checked with:

LV5350
LV5600
LV5600W
LV7300
LV7600
LV7600W
